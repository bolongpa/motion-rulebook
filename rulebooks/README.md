# rulebooks/

Rulebooks are **generated by the workflow**, not shipped with the project.

Run the automated pipeline to produce one:

```bash
motion-rulebook describe --corpus <corpus-dir> --out described.jsonl
motion-rulebook mine --described described.jsonl --out candidates.yaml
motion-rulebook ground --candidates candidates.yaml \
    --evidence evidence.tsv --out rulebook.yaml
```

Then review/edit the YAML by hand and place the finished rulebook here.

See `demo/pokemon-gen1/` for an end-to-end demo: corpus → mined
candidates → hand-reviewed `rulebook.yaml` → prompt packs.
